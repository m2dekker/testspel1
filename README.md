# The Signal

A minimalist text-based browser game, inspired by *A Dark Room*.

You wake in a cold shack with a dead radio. Somewhere in the static, something is talking.

## Play

Open `index.html` in a browser. No build step, no dependencies.

- Progress is saved automatically in your browser.
- Turn on **sound** (top right) for static, signal tones and a voice on the numbers station.
- Tune with the slider, the `‹ ›` / `« »` buttons, or the arrow keys. A voice only comes through clearly when you're tuned exactly.
- Add `?fast` to the URL to run the game 10× faster (for testing).
